# Arrays and Methods — Java Task

## Overview

A Java console application that demonstrates arrays, static methods, loops, searching, and user input.

## Requirements

- Java Development Kit (JDK)
- Terminal or command prompt

## Features

1. Calculate the sum and average of an array.
2. Find the largest and smallest elements.
3. Count even numbers and search for a value.
4. Reverse an array without modifying the original.
5. Read student grades and count passed and failed students.
6. Validate grades to accept values from 0 to 100.

## Package and Class

- Package: `ArraysTask`
- Class: `ArraysTask`

## How to Compile

From the project root, run:

`javac ArraysTask/ArraysTask.java`

## How to Run

Run:

`java ArraysTask.ArraysTask`

## Test Data

The sample array used for Questions 1 to 4 is:

`12, 7, 25, 3, 18, 9, 30, 14`

Question 5 tests grade input for five students.

## Concepts Practiced

- Arrays
- Static methods
- Loops
- Conditional statements
- Searching
- Returning values
- Input validation
